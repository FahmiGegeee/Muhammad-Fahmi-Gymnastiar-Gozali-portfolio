## About This Project

Personal portfolio website for Muhammad Fahmi Gymnastiar Gozali — Computer Engineering fresh graduate, System Analyst, UI/UX Designer, and Application Developer.

Built with **pure HTML5 + CSS3 + Vanilla JS** — no frameworks, fully explainable to any recruiter.

| Layer | Technology |

| Styling | Mobile-first CSS3 + CSS Custom Properties |
| Interaction | Vanilla JavaScript (ES6+) |
| Fonts | Google Fonts (Syne, DM Mono, Fraunces) |
| Hosting | GitHub Pages |

## Features

- ✅ Semantic HTML5 (`<nav>`, `<main>`, `<section>`, `<footer>`, `<article>`)
- ✅ Responsive / Mobile-first CSS
- ✅ Scroll reveal animations (IntersectionObserver)
- ✅ Animated skill proficiency bars
- ✅ Custom cursor with trail effect
- ✅ Active nav link highlighting
- ✅ Hamburger menu for mobile
- ✅ All code explainable to recruiters
