## RTCC-O Prompt yang digunakan

```
Role: Kamu adalah mid-level system analyst, frontend developer, dan UI/UX designer yang berpengalaman
      membuat portfolio untuk fresh graduate tech.

Task: Buat portfolio website yang profesional, modern, dan bisa mengesankan recruiter
      untuk kandidat System Analyst / UI/UX Designer / Application Developer fresh graduate.

Context:
- Nama: Muhammad Fahmi Gymnastiar Gozali
- Background: Computer Engineering, Brawijaya University, GPA 3.64
- Pengalaman: System Analyst di PT PAL Indonesia, App Developer di Metrodata Academy
- Skills utama: System Analysis, API Development, UI/UX (Figma), Web Dev
- Target audience: HR & recruiter di perusahaan tech/digital
- Tech constraint: Pure HTML/CSS/JS — no framework, harus bisa dijelaskan ke recruiter

Constraints:
- WAJIB: Semantic HTML5 (header, nav, main, section, footer)
- WAJIB: Responsive, mobile-first CSS
- TIDAK boleh: Framework berat (React/Vue), template generic

Output:
- index.html + style.css yang siap di-deploy ke GitHub Pages
- Code harus clean, commented, dan readable
- Desain harus memorable — bukan template biasa
```

## Hasil Brainstorm

### Target Audience
- HR/Recruiter di perusahaan tech, startup, BUMN digital
- Hiring manager untuk posisi: System Analyst, BA, Junior Developer

### Tone & Aesthetic Direction
**Pilihan:** Dark editorial + tech terminal aesthetic  
**Alasan:** Mencerminkan background Computer Engineering tapi tetap professional dan modern

### Key Messages
1. "Saya bisa menjembatani business & technology"
2. "Saya bukan hanya developer, tapi saya juga analyst yang bisa code"
3. "Saya learner yang aktif (13+ sertifikasi)"

### Sections yang diperlukan
- [x] Hero — nama + tagline + CTA
- [x] About — summary + key stats
- [x] Experience — timeline 2 internship + education
- [x] Skills — technical, tools, soft skills + proficiency bars
- [x] Certifications — 12+ sertifikat
- [x] Contact — email + LinkedIn

### Differentiator Visual
- Custom cursor dengan glow effect
- Animated skill bars dengan intersection observer
- Grid background dengan blob animation
- Typography mix: Syne (display) + DM Mono (body) + Fraunces (italic accent)
